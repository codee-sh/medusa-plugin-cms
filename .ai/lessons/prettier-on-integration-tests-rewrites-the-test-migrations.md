# prettier on integration-tests rewrites the test module's migrations

`.prettierignore` keeps `src/modules/*/migrations/` as Medusa writes them, but nothing covers
`integration-tests/modules/test-content/migrations/`. The plugin's `format` and `format:check` scripts
read `src/**` alone, so the gap never shows in the gate.

Running `npx prettier --write integration-tests` to format a changed test config rewrote all twelve
migrations, their `.snapshot-test-content.json` and a model: semicolons, line breaks and blank lines,
338 lines added and 238 removed across 13 files, none of them part of the change. The SQL stays the
same, but the migrations are the user's, generated by `yarn test:db:generate`, and the diff buries the
real change.

Format only the files the change touched, by path: `npx prettier --write <file> <file>`. Never point
prettier at a folder outside `src/`.
